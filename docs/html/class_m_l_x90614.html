Detailed Description

I2C driver for the MLX90614 non-contact infrared temperature sensor.

The class supports connection checks, one-shot temperature reads, periodic updates, cached ambient/object readings, and fixed-point Fahrenheit conversion. Temperatures are represented as degrees C or F multiplied by 100.
