# CAD Files

This directory contains the mechanical CAD models, assemblies, and supporting design files used in the ME507 Marshmallow Cooker project.

## Contents

* Assembly file for the complete marshmallow cooker
* Individual part models
* Hardware: screws, nuts, etc.

## Software

The CAD models were created using SolidWorks.

## Purpose

These files document the mechanical design of the marshmallow cooker, including the rotating marshmallow assembly, vertical positioning mechanism, sensor mounting features, and overall system structure.

The CAD models were used for design iteration, interference checking, fabrication, and project documentation.
